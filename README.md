# BiteLoop — HTML, CSS & JavaScript

A responsive frontend-only food discovery and surplus-food deals website.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, layout, colours and typography
- `script.js` — food listings, search, filters, cart, simulated checkout and restaurant demo form

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For the best development experience, open the folder in VS Code and use the Live Server extension.

No npm install, React, build tool, or backend is required.

## GitHub Pages
Upload these files to the root of a GitHub repository. In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.

## Important payment note
The checkout is a visual frontend simulation only. UPI, card and net-banking choices do not connect to payment providers and no real payment is taken. A production payment gateway requires a secure backend and provider integration; never collect or store real card details in browser-only code.
